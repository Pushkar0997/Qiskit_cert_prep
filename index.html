Top 6 "Looks Easy Until Exam Day" Qiskit v2.x Traps

Review these 6 patterns whenever you feel like things are slipping from memory:

TRAP #1 • Estimator Precision vs. Shots

precision is target standard error ($\sigma \propto 1/\sqrt{\text{shots}}$). Increasing precision from 0.015625 to 0.03125 makes error coarser (2× larger), so required shots decrease by 4×!

TRAP #2 • Little-Endian Pauli Tensor Order

In Pauli('IZ'), the right-most character (Z) acts on qubit 0, and I acts on qubit 1. The matrix is $I \otimes Z = \text{diag}(1, -1, 1, -1)$.

TRAP #3 • SamplerV2 Classical Register Name

In V2 primitives, counts live under the classical register's name: res[0].data.meas.get_counts() if you used measure_all(), or res[0].data.c.get_counts() for ClassicalRegister(2, 'c').

TRAP #4 • PUB Tuple Element Order

Estimator PUB: (circuit, observable, parameter_values, precision).
Sampler PUB: (circuit, parameter_values, shots).
backend is never inside a PUB!

TRAP #5 • OpenQASM 3 Dump vs. Dumps

Write to a file stream: qiskit.qasm3.dump(qc, stream).
Return a string: qiskit.qasm3.dumps(qc).
Supported scalar types include complex, angle, duration (never char, class, or enum).

TRAP #6 • Resilience vs. Dynamical Decoupling

Zero Noise Extrapolation (ZNE) and TREX are error mitigation under options.resilience (Estimator only). Dynamical Decoupling is error suppression under options.dynamical_decoupling.
